EroDist 0.7 Arch — тестовая сборка

Arch Linux / XFCE / x86_64. Live: tester / live. RU/EN: Alt+Shift. Изменения без persistence пропадают. Secure Boot отключите.

Установка — только сначала на пустой VM-диск

Кнопка «Установить EroDist» открывает текстовый мастер Archinstall. Нужны интернет и sudo. Оставьте профиль EroDist XFCE, выберите диск/загрузчик и создайте администратора с новым паролем. Внимательно проверьте сводку: установка может удалить данные. Диск и пароль не предзаданы. После установки отключите ISO и проверьте загрузку.

Это замена Debian/Calamares, а не обновление Debian-системы. Другой профиль Archinstall не установит наше оформление и приложения.

Обновления и программы

Используется pacman с полным обновлением системы. Частичные обновления Arch не поддерживает. Каталог показывает приблизительный объём по текущей базе, итоговый план с обновлением — в терминале. Проверяйте конфликты и место. Перед крупными обновлениями проверяйте новости Arch и делайте резервные копии.

Python

python -m venv ~/project/.venv
source ~/project/.venv/bin/activate
python -m pip install requests

Не используйте sudo pip. Python из Arch включает venv и IDLE, для GUI нужен Tk из набора каталога.

Wine и EXE

Установите Wine по запросу в каталоге, затем повторно откройте доверенный EXE. Wine из Arch использует WoW64 для 32/64 бит. Это не песочница, не антивирус и не гарантия совместимости. Программа получает доступ к вашим файлам. Не запускайте Wine от root.

Другое

Игры и контроллер · OBS. Timeshift настраивается после установки; документы резервируйте отдельно. «О системе» и erodist-report собирают сведения локально.

Горячие клавиши: Super — меню, Super+E — файлы, Super+Enter — терминал, Super+I — настройки, Super+L — блокировка, Print — Flameshot.

В Hyper-V композиция по умолчанию отключена, поэтому панель непрозрачна. Это не доказанное исправление задержки. Запишите время первого и повторного открытия программ.

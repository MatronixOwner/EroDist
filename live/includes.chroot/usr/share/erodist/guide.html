EroDist 0.6

Debian 12 · XFCE · тестовая сборка amd64

Первое знакомство

Раскладки US/RU переключаются Alt + Shift. Live-пользователь: tester, пароль live. После перезагрузки изменения Live-сессии пропадают. Secure Boot отключите.

Установка — сначала на пустой диск виртуальной машины

Разметка диска может уничтожить данные. Сделайте резервную копию. Никогда не выбирайте диск с нужными файлами.

  1. Создайте VM: 2 CPU, 4 ГБ RAM, пустой виртуальный диск 25 ГБ, подключите ISO.
  2. Откройте «Установить EroDist» на рабочем столе или нажмите кнопку установки в приветствии. После предупреждения и запроса прав администратора откроется Calamares в Live-сессии. Перезагрузка для запуска не нужна.
  3. В Calamares выберите язык, часовой пояс, клавиатуру, целевой диск и пользователя. Автоматическое стирание не выбрано заранее. Проверьте сводку изменений и подтвердите установку. Для первой проверки — только пустой диск VM. Если Calamares не запускается, резервный установщик Debian доступен в загрузочном меню ISO после перезагрузки; не запускайте два установщика одновременно.
  4. Создайте собственного пользователя с новым паролем; не используйте пароль Live-сессии. Подключите интернет: настройка загрузчика и пакетов может потребовать доступ к зеркалам Debian. Не выключайте компьютер и не прерывайте установку.
  5. После установки выключите VM, отключите ISO и загрузитесь с виртуального диска.

  • ☐ Установщик завершился без ошибок.
  • ☐ После отключения ISO загружается установленная система.
  • ☐ Вход новым пользователем; сохранённые файлы остаются после перезагрузки.
  • ☐ Приветствие, обои, русский интерфейс и RU/EN работают в установленной системе.
  • ☐ Обновления устанавливаются, после перезагрузки система работает.
  • ☐ Отчёт открывается для просмотра, настройка «Не показывать при входе» сохраняется.

Обновления

Откройте «Проверить обновления» в приветствии или приложение обновлений в меню. Оно использует PackageKit и репозитории Debian; для установки может потребоваться пароль администратора. Во время установки обновлений не выключайте компьютер. В Live-сессии изменения не сохраняются. Автоматическая отправка данных и сторонние репозитории не добавлены.

Ошибки и диагностика

В приветствии нажмите «Создать и просмотреть отчёт» или запустите erodist-report. Отчёт сохраняется локально с доступом только вашему пользователю. Проверьте текст в редакторе и удалите личные сведения. Ничего не отправляется автоматически.

Отправьте имя ISO, BIOS/UEFI, конфигурацию VM/ПК, шаги воспроизведения, ожидаемый и фактический результат и скриншот. Отчёт приложите вручную в GitHub Issues или отправьте описание в чат.

Окно приветствия можно снова открыть из меню приложений, даже если вы отключили автозапуск.

Новое в 0.3: программы и Python

Центр настроек доступен из приветствия, панели и меню. В каталоге выберите приложение, посмотрите пакеты и примерный размер, затем подтвердите запуск установки. APT ещё раз покажет окончательный план в терминале. Нужны интернет и права администратора. Если индекс устарел, откройте обновления. Ошибки APT остаются видны в терминале.

Пункт Python устанавливает Python 3, pip, venv и IDLE. Python уже используется компонентами системы; каталог добавляет инструменты разработки. Создайте окружение:

python3 -m venv ~/my-project/.venv
source ~/my-project/.venv/bin/activate
python -m pip install requests

Не используйте sudo pip и не меняйте системный Python.

Клавиши и панель

  • Super — меню приложений
  • Super + E — файлы
  • Super + Enter — терминал
  • Super + L — блокировка
  • Super + I — центр настроек
  • Print Screen — выделение области и пометки Flameshot
  • Alt + Shift — RU/EN

В нижней панели: меню, файлы, браузер, настройки, окна, раскладка, системный лоток с сетью, звук, питание и часы. Состав можно изменить в настройках панели.

Timeshift и ноутбуки

Снимки включайте только после установки на диск: в центре настроек откройте Timeshift, выберите место и расписание. Автоматические снимки по умолчанию не включены. Для ext4 используйте RSYNC; BTRFS требует совместимой разметки. Личные документы резервируйте отдельно. Восстановление может перезаписать системные изменения — сначала проверяйте на VM.

Питание, яркость, поведение крышки и сон настраиваются в центре настроек. На ноутбуке проверьте: питание от сети и батареи, яркость, тачпад, сон/пробуждение и Wi-Fi после сна. Совместимость конкретного железа не гарантируется одной сборкой ISO. Автоматические настройки TLP не навязываются.

О системе и Windows EXE — 0.5

«О системе EroDist» доступно в меню, приветствии и центре настроек. Кнопка копирования переносит сведения в буфер обмена. Данные собираются локально, ничего не отправляется автоматически.

Для Windows-программ откройте «Windows-программы (Wine)» или EXE через файловый менеджер. Первый запуск предложит открыть каталог: выберите Wine, просмотрите размер и подтвердите установку. Устанавливаются Wine, 64-битные и 32-битные компоненты из Debian. Архитектура i386 заранее разрешена в APT; её пакеты не предустановлены в ISO. Если индекс устарел или недоступен, обновите списки пакетов и повторите.

Wine не гарантирует работу всех программ и НЕ является песочницей. Windows-программа получает доступ к вашим файлам и сети. Запускайте только доверенные EXE, никогда не используйте sudo/root. Проверка заголовка EXE определяет формат, но не проверяет файл на вирусы. Драйверы, античиты, приложения Microsoft Store и часть игр могут не работать. MSI и DOS-программы этот запускатель не обрабатывает.

После установки Wine повторно откройте EXE. Перед каждым запуском есть подтверждение. Используется отдельный 64-битный Wine-префикс ~/.local/share/erodist/wine/default (поддерживает x86 через Wine32). Первый запуск и инициализация могут занять минуты. Игры могут потребовать дополнительные графические библиотеки; автоматическая установка DXVK не включена.

При ошибке отображается путь к приватному журналу в ~/.local/state/erodist/wine. Перед отправкой проверьте журнал на личные данные. В Live-сессии загруженные компоненты, префикс и Windows-программы без persistence исчезают после перезагрузки, поэтому лучше устанавливать Wine после установки EroDist на диск.

Тест 0.5: проверьте копирование сведений, отмену запуска EXE, установку Wine, затем известные доверенные x86/x86-64 программы, включая имя файла с пробелами. Успех сборки не доказывает совместимость конкретного приложения.

Новое в 0.6: игры, оформление, запись

В меню, приветствии и центре настроек есть «Игры и запись экрана». Инструкция Steam / Proton / геймпад · Инструкция записи экрана и звука в OBS.

В каталоге добавлены Steam с Mesa/Vulkan, инструменты геймпада и OBS — установка по запросу, в ISO их нет. Чёрные градиентные обои сохранены. Тема EroDist-Black на базе Arc-Dark, полупрозрачная панель, тёмный терминал; без отдельного композитора и размытия. Оформление сторонних приложений, например клиента Steam, зависит от самих приложений.

Новые значения оформления рассчитаны на чистый профиль. Пользовательские настройки существующего профиля не затираются. Чтобы выбрать тему вручную: Центр настроек → Оформление → EroDist-Black; оформление окон — Диспетчер окон. Встроенный поиск существующего меню не менялся; отдельный поиск и связь с телефоном не добавлены.

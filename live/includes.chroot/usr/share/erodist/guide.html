EroDist 0.2

Debian 12 · XFCE · тестовая сборка amd64

Первое знакомство

Раскладки US/RU переключаются Alt + Shift. Live-пользователь: tester, пароль live. После перезагрузки изменения Live-сессии пропадают. Secure Boot отключите.

Установка — сначала на пустой диск виртуальной машины

Разметка диска может уничтожить данные. Сделайте резервную копию. Никогда не выбирайте диск с нужными файлами.

  1. Создайте VM: 2 CPU, 4 ГБ RAM, пустой виртуальный диск 25 ГБ, подключите ISO.
  2. Кнопка «Установить систему» в приветствии предлагает перезагрузку. Это не установщик внутри рабочего стола. Сохраните файлы и подтвердите.
  3. В загрузочном меню ISO выберите Install / Graphical install. Если пункта не видно, проверьте подменю установщика.
  4. Выберите язык, часовой пояс и раскладку, создайте собственного пользователя с новым паролем. Для первой проверки используйте автоматическую разметку только пустого виртуального диска.
  5. После установки выключите VM, отключите ISO и загрузитесь с виртуального диска.

Чек-лист тестировщика

Заполните отдельно для BIOS и UEFI. Успех сборки не заменяет эту проверку.

  • ☐ Live: рабочий стол, оформление, приветствие и раскладка Alt + Shift.
  • ☐ Интернет, DNS, браузер, звук, изменение разрешения.
  • ☐ Установщик завершился без ошибок.
  • ☐ После отключения ISO загружается установленная система.
  • ☐ Вход новым пользователем; сохранённые файлы остаются после перезагрузки.
  • ☐ Приветствие, обои, русский интерфейс и RU/EN работают в установленной системе.
  • ☐ Обновления устанавливаются, после перезагрузки система работает.
  • ☐ Отчёт открывается для просмотра, настройка «Не показывать при входе» сохраняется.

Обновления

Откройте «Проверить обновления» в приветствии или приложение обновлений в меню. Оно использует PackageKit и репозитории Debian; для установки может потребоваться пароль администратора. Во время установки обновлений не выключайте компьютер. В Live-сессии изменения не сохраняются. Автоматическая отправка данных и сторонние репозитории не добавлены.

Ошибки и диагностика

В приветствии нажмите «Создать и просмотреть отчёт» или запустите erodist-report. Отчёт сохраняется локально с доступом только вашему пользователю. Проверьте текст в редакторе и удалите личные сведения. Ничего не отправляется автоматически.

Отправьте имя ISO, BIOS/UEFI, конфигурацию VM/ПК, шаги воспроизведения, ожидаемый и фактический результат и скриншот. Отчёт приложите вручную в GitHub Issues или отправьте описание в чат.

Окно приветствия можно снова открыть из меню приложений, даже если вы отключили автозапуск.

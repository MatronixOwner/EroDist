# Центр настроек EroDist и Graphite Icons 0.1.1

Новая разработка по прямому запросу пользователя: свой центр настроек и новые иконки приложений. Не продолжение отменённого переноса Mint. Пакеты независимы от `packages/neon-system`, старого центра управления, редакций и первого запуска.

Ранее выданный **чистый ISO** остался без этих пакетов, но теперь доступен [новый ISO с предустановленными приложением, иконками и Wine](iso-settings-wine.md). Старый файл автоматически не меняется.

## Что сделано

- `erodist-control-center`: отдельное приложение Qt 6/PySide6, разделы «Главная», «Оформление», «Устройства», «Сеть», «Приложения», «О системе». Карточки, навигация клавиатурой и прокрутка. Нет отдельного поиска, телефона, редакций, мастеров или фоновой службы.
- Настройки открываются в настоящих штатных модулях KDE. Центр не подменяет их, не объявляет настройку выполненной после открытия окна и не запрашивает root. Административные операции, например изменение системного времени, авторизует сам KDE.
- Смена значков — настоящим `plasma-changeicons` из KDE libexec, без оболочки и изменения системных файлов. Ожидается завершение процесса, выводится ошибка при неуспехе. При закрытии во время применения приложение просит дождаться завершения.
- `erodist-icons`: оригинальные графитовые SVG для файлов, терминала, браузера, магазина, редактора и разделов настроек. Иконка центра создана генератором изображений (`design/erodist-control-center.png`); установочные PNG уменьшены до 256px. SVG воспроизводятся `scripts/erodist-icons.py`. Breeze/hicolor используются для остальных значков, то есть это не замена всех иконок всех приложений.
- Локальная сводка ОС, ядра, архитектуры и RAM. Нет сети/телеметрии, журналов, IP/MAC, имён пользователей или серийных номеров. Экспорт только по нажатию, показанный текст, атомарная запись с правами 0600; отмена диалога ничего не сохраняет.

## Установка на KDE neon

Скачайте оба файла из одного выпуска в одну папку. В терминале этой папки:

```sh
sudo apt install ./erodist-icons.deb ./erodist-control-center.deb
```

Откройте **«Центр настроек EroDist»** из меню приложений. В «Оформление» нажмите «Иконки EroDist», чтобы сменить значки только для текущего пользователя. Некоторые приложения могут держать старые значки до перезапуска.

Чтобы вернуться к прежней теме, откройте штатные настройки KDE → «Цвета и темы» → «Значки» и выберите Breeze/прежнюю тему. Перед удалением `erodist-icons` сначала переключитесь на другую тему. Установка сама по себе не переписывает пользовательские настройки.

## Проверки

[Успешный native CI исходника f0b5fe4](https://github.com/MatronixOwner/EroDist/actions/runs/41060009653):

- 46 unit-тестов, один прежний Pillow-тест пропущен в системном Python.
- Оба DEB установлены через APT в настоящий подписанный rootfs neon из закреплённого ISO.
- Идентификаторы используемых KCM проверены по `kcmshell6 --list`.
- Все шесть страниц проверены в 800×600/1060×740 и при шрифте 13 в 800×600/640×460: границы видимых элементов и высота перенесённого текста, отсутствие горизонтальной прокрутки.
- Проверены клики, навигация клавиатурой, передача команды с аргументами, отсутствие компонента, отмена экспорта, сохранение точного текста и права 0600.
- Проверена загрузка всех восьми именованных значков из установленной темы.
- Настоящий `/usr/lib/x86_64-linux-gnu/libexec/plasma-changeicons` записал `Icons/Theme=EroDist` в изолированную конфигурацию; повторное применение прошло успешно.

Полный сеанс Plasma/Wayland/X11, визуальное обновление панели и меню вживую, изменение параметров каждого внешнего KCM и Hyper-V ещё не проверены. Проверка записи темы в изолированный конфиг не выдаётся за тест загруженного рабочего стола.

## Разработка

`bash scripts/desktop-package.sh` создаёт два DEB в игнорируемой `artifacts/desktop/`. Упаковка исключает `.pyc`/`__pycache__`. Native CI — `.github/workflows/desktop.yml`, `scripts/desktop-native-check.sh`, `scripts/desktop-smoke.py`. Старый Qt-прототип не импортируется и не устанавливается.

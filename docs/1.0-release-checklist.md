# Допуск к стабильной EroDist 1.0.0

Статус: **не допущена; RC1 опубликован**. Автоматическая сборка [№27](https://github.com/d50130483-ship-it/EroDist/actions/runs/39326316923) успешна, код ISO `05bc350`. Незавершённые проверки не считаются пройденными. Работа выполняется только с пустыми виртуальными дисками. Никакой автоматической разметки физического диска для теста.

## Автоматизация (выполняется на каждой сборке; результат смотреть в конкретном run)
- [x] GPG и SHA256 исходника Mint, сборка Debian-пакетов.
- [x] Unit-тесты, симуляция APT всех редакций.
- [x] GTK smoke: настройки, приветствие, отчёт; страница редакции; отказ сети, повтор проверки, согласие Steam.
- [x] Manifest: installer-only пакет внесён в список удаления; system пакет не внесён. Фактическое удаление после установки ещё не проверено.
- [x] BIOS/UEFI-записи и SHA256 ISO; публикация ZIP с одним ISO.

## Hyper-V — отдельный блок
Сравнить с неизменённым Mint 22.3 на той же VM, при одинаковых RAM/vCPU/диске, настройках хоста и состоянии обновлений. Не объяснять регрессию ресурсами без сравнения.

Измерить холодный и повторный запуск центра настроек, Nemo, терминала, браузера; записать время и загрузку CPU/диска. Проверить сеть, разрешение экрана, звук, выключение и повторную загрузку. Проверить поколение 1 (BIOS) и 2 (UEFI, Secure Boot off). Приложить сведения из отчёта и описание воспроизведения, не полный журнал с личными данными. **Сейчас всё это не проверено.**

## Условия стабильного релиза
- Пройдены полные циклы установки/загрузки всех редакций и восстановлены результаты.
- Блокирующие ошибки установки исправлены; поведение при частичной установке описано и проверено.
- Проверены Hyper-V и Windows ZIP; известные ограничения явно опубликованы.
- Есть проверенная ссылка скачивания, SHA256 и инструкция, срок хранения указан честно.
- Кандидат не переименовывается в stable лишь из-за успешной сборки.

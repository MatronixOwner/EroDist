## Состав

Новая тестовая сборка на закреплённой KDE neon Desktop User Edition. Поверх штатной системы установлены:

- `erodist-control-center` и `erodist-icons` — новые самостоятельные пакеты EroDist.
- `wine`, `wine64`, `wine32:i386`, `fonts-wine` из штатных репозиториев основы. Включена архитектура i386; не используется сторонний WineHQ-репозиторий или скрипт установки из интернета.
- Тема значков EroDist выбрана в `/etc/skel/.config/kdeglobals` для новых Live/устанавливаемых пользователей. Профили существующих пользователей не переписываются.

Оба приложения находятся непосредственно в `casper/filesystem.squashfs`, а не устанавливаются после загрузки сетью. Штатный Calamares разворачивает этот filesystem; список удаляемых Live-пакетов не меняется и не содержит Wine или новых пакетов EroDist. Центр запускается из меню «Центр настроек EroDist». Wine используется, например, командой `wine /путь/к/программе.exe`.

**Wine не гарантирует совместимости со всеми Windows-программами, играми, DRM и античитами.** Дополнительные .NET/Gecko/компоненты конкретного приложения могут потребовать загрузки и ручной настройки. Wine не является песочницей: запускайте только доверенные EXE.

## Сборка и проверки

План — `neon/image.json`, пайплайн — `.github/workflows/desktop-iso.yml`. Для намеренной новой сборки commit message должен содержать `[desktop-iso]`. Сборка выполняется только на рабочей ветке с Ubuntu runner, sudo и достаточным местом; локальная упаковка DEB не требует сборки ISO.

`scripts/desktop-iso.sh`:

1. Проверяет исходный ISO по закреплённым SHA256 и полному GPG fingerprint.
2. Устанавливает два новых DEB и Wine в извлечённый настоящий rootfs neon; блокирует запуск системных служб во время APT. Kernel/module package versions не должны изменяться.
3. Выполняет Qt-тесты нового центра и проверку идентификаторов KCM.
4. Проверяет встроенную команду Wine `cmd /c echo` в **разных** `win32`/`win64` временных префиксах. .NET/Gecko отключены только в окружении smoke, не глобально для будущего пользователя. После теста wineserver остановлен; префиксы удалены. `/root/.wine` не допускается в образе.
5. Восстанавливает исходные `resolv.conf` и policy-rc.d, снимает bind mounts, очищает временные DEB/тесты и кэш APT. Проверяет отсутствие host mounts перед упаковкой.
6. Создаёт squashfs, manifest/size, обновляет medium MD5. Загрузочные образы/каталог исключены из medium MD5, поскольку boot replay перемещает/патчит их штатным механизмом xorriso.
7. Переносит штатные гибридные BIOS/UEFI записи через `-boot_image any replay`. Ядро и initrd не заменяются и не пересобираются.
8. Извлекает **готовый ISO** обратно, проверяет medium MD5, побайтовую идентичность squashfs, исходных kernel/initrd и статусы нужных пакетов в конечной файловой системе.

Это проверки состава, Qt и встроенных CLI Wine, **не полное прохождение загрузки и установки в VM**. Hyper-V, Secure Boot и произвольные Windows-приложения отдельно ещё не проверены. Поддержка Wine GUI не выводится из успешного headless `cmd` smoke.

Архив для пользователя содержит **один полный ISO**, не части и не скрипты сборки. Старый чистый ISO и уже установленная с него система автоматически не изменяются. Для нового Live-образа скачайте новый архив и подключите/запишите распакованный ISO; при установке на диск внимательно проверьте разметку и заранее сохраните данные.

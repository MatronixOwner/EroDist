# EroDist

Тестовый Linux-дистрибутив на **Debian 12 Bookworm**, **XFCE**, архитектура **amd64**.
Это ранняя сборка для проверки, не готовая замена основной ОС.

## Скачать и проверить

Готовые ISO после успешной сборки появляются в [Releases](https://github.com/d50130483-ship-it/EroDist/releases).
Ход сборки и ошибки доступны в [Actions](https://github.com/d50130483-ship-it/EroDist/actions/workflows/iso.yml).
Если сборка не прошла, нового ISO в Releases не будет.

1. Скачайте ISO и `SHA256SUMS` из **одного релиза**.
2. В папке загрузки выполните `sha256sum -c SHA256SUMS` (Linux).
   В Windows: `Get-FileHash .\erodist-0.6.0-amd64.iso -Algorithm SHA256`, сравните с `SHA256SUMS`.
3. Сначала загрузите ISO в VM: 2 CPU, 4 ГБ RAM, 25 ГБ виртуальный диск.
4. Выберите Live. Логин **tester**, пароль **live**, доступен `sudo`.
5. Проверьте рабочий стол, сеть, звук, браузер, перезагрузку, затем установку на **пустой виртуальный диск**.

Поддерживаются BIOS и UEFI; **Secure Boot отключите**. Работа на конкретном железе пока не проверена.
Live-сессия без persistence: изменения исчезнут после перезагрузки.
Основной установщик EroDist (Calamares) запускается из Live-сессии через приветствие или ярлык на рабочем столе. Резервный установщик Debian доступен в загрузочном меню. Установка/запись ISO может уничтожить данные — сделайте резервную копию.
Не используйте известный Live-пароль в установленной системе: создайте своего пользователя в установщике.

## Сборка

GitHub Actions собирает ISO в привилегированном контейнере Debian 12 и публикует prerelease с контрольной суммой.
Автозапуск настроен для изменений сборки в рабочей ветке `arena/a42c77fd-erodist`; также доступен ручной `workflow_dispatch` (когда workflow есть в основной ветке).
Требуется разрешение GitHub Actions на запись содержимого репозитория. Сборка обычно занимает десятки минут.

Локально на Linux с Docker (нужны интернет, root-привилегии контейнера и примерно 15–20 ГБ свободного места):

```sh
docker run --rm --privileged -v "$PWD:/workspace" -w /workspace debian:bookworm bash -euxo pipefail -c '
  apt-get update
  apt-get install -y --no-install-recommends cpio file gzip xz-utils live-build debootstrap xorriso squashfs-tools isolinux syslinux-common grub-pc-bin grub-efi-amd64-bin mtools dosfstools ca-certificates
  bash scripts/build.sh
'
```

Результат: `artifacts/erodist-0.6.0-amd64.iso` и `artifacts/SHA256SUMS`.
ISO и рабочий каталог сборки не хранятся в Git. Используются актуальные зеркала Debian, поэтому сборки не побитово воспроизводимы.
Исходники пакетов и их лицензии доступны в Debian; пакеты с non-free firmware имеют отдельные условия распространения.

## Новое в 0.2.0

- Обои EroDist, Arc-Dark и значки Papirus-Dark, оформление приветствия LightDM.
- Локальное GTK-окно приветствия: инструкция, обновления, диагностика, ссылка на баги.
- Кнопка установки **предлагает перезагрузку в меню ISO**, где запускается установщик Debian. Она не запускает разметку дисков сама.
- RU/EN: Alt + Shift, русская локаль, английская резервная локаль.
- Графическое приложение обновлений PackageKit (`gpk-update-viewer`), штатные репозитории Debian.
- Создание приватного локального отчёта с открытием в редакторе. Автоотправки нет.
- Автозапуск приветствия можно отключить; вручную оно доступно в меню.

Чек-лист проверки установки включён в образ: `/usr/share/erodist/guide.html`.
Проверяйте BIOS и UEFI отдельно, отключив ISO после установки. Проверки исходников и успешная сборка **не доказывают** работоспособность установленной системы.

Проверки исходников: `python3 -m unittest discover -s tests -v`.

## Версия 0.3.0

Центр настроек, нижняя панель XFCE с Whisker Menu и RU/EN, горячие клавиши, Flameshot с пометками, Timeshift (настраивается пользователем после установки), настройки питания. Выбранные чёрные градиентные обои сохранены.

Каталог программ: Python 3 + pip + venv + IDLE, VLC, Telegram, GIMP, LibreOffice. Установка из настроенных репозиториев APT: сначала расчёт пакетов и оценки размера, затем подтверждение и авторизация через polkit, затем финальный план и подтверждение APT в терминале. Приложения не загружаются заранее в ISO. Используйте виртуальные окружения Python, не `sudo pip`.

Timeshift не заменяет резервное копирование документов. Сон, яркость, восстановление снимков и работа установленной системы требуют отдельных проверок по инструкции в образе. Новые настройки панели/клавиш рассчитаны на новые профили пользователя; существующие пользовательские настройки не затираются.

## Версия 0.4.0: установщик EroDist

Calamares с названием EroDist, монохромной тёмной темой и слайдами. Запуск прямо из Live-сессии через приветствие, меню или ярлык «Установить EroDist». Фиксированный root-wrapper через polkit: проверка Live-режима и наличия squashfs, блокировка повторного запуска, восстановление Live fstab после выхода. Работа с дисками остаётся в Calamares.

Используется последовательность модулей **из Debian-пакета `calamares-settings-debian`**, а не самописная разметка/копирование. При сборке меняются branding, EFI ID / имя GRUB, явное финальное подтверждение, отсутствие заранее выбранного стирания диска и минимумы 25 ГиБ диска / 2 ГиБ RAM. Во время записи отмена отключена, чтобы не обрывать установку. Подключите интернет: установка загрузчика и настройка пакетов могут потребовать зеркала Debian.

Сначала тестируйте только на пустом виртуальном диске, отдельно BIOS/UEFI. Сборка и проверки конфигурации не заменяют полную установку с последующим отключением ISO. Secure Boot не заявлен. Резервный установщик Debian оставлен в меню ISO. Предыдущие разделы README описывают историю версий; способ запуска без перезагрузки добавлен в 0.4.

## Версия 0.5.0: сведения о системе и Wine

«О системе» показывает версию, ядро, CPU, RAM, графику/драйвер, BIOS/UEFI и Live/установленный режим. Копирование в буфер, без автоматической отправки.

Wine устанавливается **по запросу**, а не предустановлен: каталог предлагает `wine`, `wine64`, `wine32:i386`, `fonts-wine`. Включена архитектура APT i386, чтобы расчёт зависимостей и установка поддерживали оба варианта EXE. Требуются интернет и значительный объём диска; точный план проверяется перед установкой. Не все Windows-программы совместимы, Wine не является песочницей.

Запускатель `erodist-wine [путь.exe]` доступен в меню и через MIME-ассоциации для EXE. Проверяет формат x86/x86-64 PE (не безопасность файла), требует подтверждения и не работает от root. Использует отдельный пользовательский префикс; журналы локальные с правами 0600. Никаких скачиваний EXE или скрытого запуска. В существующем профиле пользовательские MIME-ассоциации могут иметь приоритет — выберите «Открыть с помощью Windows-программы (Wine)».

Проверки чистых функций покрывают сведения, EXE-заголовки и передачу имён с пробелами/спецсимволами без shell. Реальная совместимость x86/x86-64 приложений и GUI требуют проверки в установленной системе.

## Версия 0.6.0: игры, чёрный стиль и OBS

- `erodist-play`: вкладки игр и записи, запуск установленного Steam, jstest-gtk и OBS; при отсутствии — подтверждённый переход к нужному пункту каталога. Никакой установки/записи при открытии окна.
- Каталог: Steam (`steam-installer`, `steam-devices`, Mesa Vulkan amd64/i386, 32-битная Mesa), отдельный набор проверки геймпада, `obs-studio`. Не предустановлены, нужен интернет/место; Valve-клиент, Proton и игры скачиваются отдельно пользователем. Проприетарные NVIDIA-библиотеки не входят в набор Mesa.
- EroDist-Black: собственные GTK-переопределения на базе установленной Arc-Dark, оконные декорации из пакета Arc, Papirus-Dark, чёрная полупрозрачная панель и тёмный терминал. Обои не менялись. Только встроенный xfwm4-композитор, без blur/отдельного демона. Лицензия базовой темы: `/usr/share/doc/arc-theme/copyright` в ISO.
- Офлайн-инструкции `/usr/share/erodist/gaming.html` и `recording.html`: Proton, Steam Input, особенности GPU, экран/окно и PulseAudio в OBS, сохранение видео и конфиденциальность.
- Связь с телефоном и отдельный поисковый запускатель не добавлены.

Автотесты исходников и разрешение зависимостей APT не заменяют проверку игры/античита, геймпада и записи на конкретном железе. Оформление применяется как начальное для новых профилей, а не насильно поверх пользовательских настроек.

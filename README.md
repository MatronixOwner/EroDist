# EroDist — Arch Linux edition

**0.7.0-arch1 — новая тестовая база Arch Linux, XFCE, x86_64.**
Это не обновление установленного Debian: сделайте резервные копии и используйте отдельную VM/пустой диск. Старые Debian ISO 0.1–0.6 остаются в [Releases](https://github.com/d50130483-ship-it/EroDist/releases).

## Скачать и проверить

[Releases](https://github.com/d50130483-ship-it/EroDist/releases) · [Сборки](https://github.com/d50130483-ship-it/EroDist/actions/workflows/iso.yml)

Скачайте ISO и `SHA256SUMS` из одного релиза. Linux: `sha256sum -c SHA256SUMS`; Windows: `Get-FileHash .\erodist-0.7.0-arch1-x86_64.iso -Algorithm SHA256` и сравните хеш. Не используйте образ с несовпадающей суммой.

Начните с VM: 2 CPU, 4 ГБ RAM, диск 30 ГБ, Secure Boot выключен. BIOS и UEFI предусмотрены archiso. В Live: пользователь **tester**, пароль **live**. Root заблокирован; для административных действий используется sudo с паролем. Live-сессия без persistence не сохраняет файлы после перезагрузки.

## Что перенесено

- XFCE, русский интерфейс, RU/EN Alt+Shift, панель, горячие клавиши, чёрный градиент, EroDist-Black и тёмный терминал.
- Приветствие, центр настроек, «О системе», локальный диагностический отчёт.
- Каталог приложений на **pacman**: Python/pip/Tk (venv и IDLE входят в Python), VLC, Telegram, GIMP, LibreOffice, Wine, Steam, OBS и тест контроллера.
- Обновления и установка: **полная транзакция `pacman -Syu`**. Частичные обновления не поддерживаются Arch. Предпросмотр каталога приблизительный; итоговый план и подтверждение — в терминале. AUR и сторонние репозитории автоматически не добавляются.
- Официальный multilib для Steam. Wine использует актуальную архитектуру WoW64 из пакета Arch, а не Debian `wine32:i386`.
- Игровой раздел, Steam/Proton и OBS по запросу, Flameshot, Timeshift после установки.

Композиция XFWM отключена по умолчанию для сравнения скорости в Hyper-V: панель пока непрозрачная. Это экспериментальная настройка, не доказанное исправление старой задержки. Новый Live-образ использует Zstandard вместо XZ для более быстрой распаковки программ. Скорость на конкретном хосте нужно измерить.

## Установка

**Calamares с Debian-модулями не перенесён:** эти модули несовместимы с Arch. Кнопка «Установить EroDist» запускает официальный **текстовый мастер Archinstall в терминале**, с локальным профилем **EroDist XFCE**. Интернет обязателен. Это явное изменение интерфейса, не графический Calamares.

1. Сначала пустая VM. Откройте установщик из приветствия/меню, подтвердите предупреждение и sudo.
2. Оставьте профиль **EroDist XFCE**: он устанавливает пакеты рабочего стола и наши приложения/оформление. Другой профиль даст другую систему.
3. Выберите диск/разметку, загрузчик, язык, часовой пояс и создайте своего пользователя **с правами администратора** и новым паролем. Пароли и диск не предзаданы в конфигурации EroDist.
4. Проверьте полную сводку и финальное подтверждение Archinstall. Разметка может уничтожить данные.
5. После завершения отключите ISO и проверьте загрузку с диска. Отдельно протестируйте BIOS и UEFI. Не проверяйте шифрование/dual-boot на дисках с ценными данными в первом тесте.

Профиль использует API официального Archinstall и обычную сетевую установку, не копирует Live-аккаунт/пароль на диск. Оболочка не выполняет самописную разметку. Ручная установка и загрузка требуют проверки: успех сборки не заменяет тест установки.

## Запуск EXE / игры / запись

«Windows-программы (Wine)» предлагает установку Wine из каталога и повторный запуск EXE. Только доверенные x86/x86-64 PE-файлы. Wine/Proton **не песочница** и не гарантируют совместимость, особенно драйверов, DRM и античитов. Не используйте sudo для Windows-программ. Префикс и журналы остаются локально в домашней папке.

Steam/OBS загружаются пользователем из официальных репозиториев. Игры и Proton скачиваются самим Steam. Mesa/Vulkan не заменяет проприетарные библиотеки NVIDIA. Запись OBS начинается только вручную; проверьте источники и путь сохранения. Инструкции: `/usr/share/erodist/guide.html`, `gaming.html`, `recording.html`.

## Сборка

```sh
docker run --rm --privileged -v "$PWD:/workspace" -w /workspace archlinux:latest bash -euxo pipefail -c '
  pacman-key --init
  pacman-key --populate archlinux
  pacman -Syu --noconfirm archiso archinstall python
  bash scripts/build.sh
'
```

Нужны интернет, Docker с root-привилегиями и примерно 25 ГБ свободного места. Сборка начинается с чистого `build/`; используйте новую рабочую копию для повторной сборки. `archiso` сохраняет поддерживаемые upstream настройки загрузки releng. Используются текущие rolling-репозитории, сборка не побитово воспроизводима. ISO/рабочая директория в Git не хранятся; результат в `artifacts/`.

Проверки: `python3 -m unittest discover -s tests -v`. На сборщике дополнительно проверяются разрешение пакетов каталога и импорт профиля через установленный Archinstall. Они **не тестируют загрузку, установку, игры или восстановление снимков**. Исходники/лицензии базовых пакетов — в Arch Linux; EroDist не является официальным образом Arch Linux.

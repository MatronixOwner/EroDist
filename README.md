# EroDist — новая разработка на KDE neon / Plasma

**Решение пользователя: начинаем с нуля, без переноса прежнего EroDist.** Основа остаётся KDE neon Desktop User Edition. Новый ISO ещё не выпущен.

Home / Pro / Program, старый установщик, первый запуск, центр управления и прочие прежние функции не входят в новый план автоматически. Ранее созданный Qt/Plasma-прототип — эксперимент, а не утверждённая основа новой системы. Исходники и старые выпуски оставлены для истории, ничего не удалено.

Начальная точка — чистый официальный neon со штатным Plasma и установщиком. Новый состав и оформление разрабатываются отдельно; прежний план переноса отменён. Проверка подписи исходного ISO остаётся полезной проверкой основы, но не доказательством готовности нового EroDist. [Решение и история исследований](neon/README.md).

Сборка Mint сохранена для ручного запуска, автоматический push-build отключён. У старых Actions ZIP ниже заявленный срок хранения закончился 27 октября 2026 года; наличие файлов не гарантируется. Не выдаём эти архивы за новые neon ISO.

# Обновление брендинга — EroDist 1.0 RC2

Опубликован новый образ с заменой визуальных логотипов Mint: меню/значки дистрибутива, системные изображения, Plymouth, экран входа, слайды установщика и фон загрузочного меню. Пакеты, ключи, репозитории, названия тем, лицензии и указание Mint как основы не удаляются. Это изменение внешнего вида, не переход на другую базу.

Замены зарегистрированы через dpkg-divert и повторяются при обновлении пакетов с изображениями. Оригиналы сохраняются под неиспользуемым расширением `.erodist-original`, чтобы удаление EroDist-пакета могло восстановить их. В initramfs включена собственная тема; ядро остаётся оригинальным. BIOS/UEFI-конфигурации и загрузочные бинарники не переписываются. Полная визуальная проверка всех окон и стадий загрузки ещё нужна; автоматический поиск по известным путям не распознаёт логотипы внутри произвольных скриншотов.

# EroDist 1.0 RC1 — кандидат в релиз

Основа: **Linux Mint 22.3 Cinnamon x86_64**. Создатель: **d50130483-ship-it**.
Это производная Mint, не официальный выпуск. **RC1 не является стабильной 1.0.0**: полная установка и загрузка, Hyper-V и распаковка на реальной Windows ещё требуют проверки.

## Новое в кандидате 1.0

- **Первый запуск:** по одному явному нажатию открывает обновления, драйверы, язык, раскладку, время и Timeshift. Можно напомнить позже или больше не показывать. Автоматически открывается только при завершённой установке, не в Live. Отметка хранится отдельно у каждого пользователя; фоновой службы нет. Экран не проверяет, выполнил ли пользователь настройку во внешнем инструменте, и не ставит драйверы без согласия.
- **Диагностика:** просмотр текста → явное сохранение именно показанного отчёта. Файл создаётся с правами `0600`; автоматической отправки нет. Отчёт содержит версию/редакцию, состояние установки, ядро, CPU, RAM, GPU и факт обнаружения VMBus. Не собирает имена пользователя/хоста, IP/MAC, серийные номера, личные файлы и журналы. Предварительный просмотр остаётся обязательным перед передачей отчёта кому-либо.
- **Подготовка установки:** Pro/Program проверяют доступ к архиву Ubuntu асинхронно до перехода к дискам. При ошибке можно перепроверить сеть. Это не проверка всех зеркал и не проверка GPG — подписи и зависимости обслуживает APT.
- **Пакеты редакции:** до их загрузки проверяется запас места в `/target` (после копирования базовой системы), затем разрешение зависимостей. Размеры — консервативные пороги, не точный прогноз всех обновлений. Сетевые таймауты и повторы APT ограничены. В установщике появляется сообщение о том, какая редакция загружается.
- **Program:** тёмный профиль GNOME Terminal и двухстрочное цветное приглашение Bash в шаблоне нового пользователя. Без сетевых скриптов, плагинов и фоновых команд.
- **Скачивание:** каждая успешная новая сборка публикует один ZIP с полным ISO в Actions; части в Releases остаются запасным вариантом.

## Три редакции

Выбор **только в установщике**, без переключателя после установки.

| Редакция | Состав | Рекомендуемый диск |
|---|---|---|
| Home | Браузер, видео, общение и офис из стандартного Mint; дополнительных загрузок редакции нет | от 30 ГиБ |
| Pro | Home + Steam, GameMode, MangoHud, Mesa/Vulkan 32/64 бит | от 60 ГиБ |
| Program | Home + Git, Python/pip/venv/Tk, C/C++, Clang, CMake, Ninja, GDB, Node.js/npm, Geany, **Godot 3**, Blender | от 70 ГиБ |

Pro и Program требуют интернет и официальные репозитории Mint/Ubuntu. Для Pro обязательно явное согласие с условиями Valve. Steam может обновить клиент при первом запуске; игры и Proton скачиваются отдельно. Unity/Unreal не включены. Proprietary GPU driver не выбирается вслепую. Скорость игр и совместимость античитов не гарантируются.

## Безопасность и известные ограничения RC1

- Сначала **пустая VM**, Secure Boot off. Перед настоящим диском — резервная копия. Не запускайте несколько установщиков одновременно.
- Разметка, экран дисков, подтверждение записи и загрузчик — штатные Mint/Ubiquity. Собственная округлённая страница выбора редакции не означает полностью переписанный Windows-подобный мастер.
- Проверка сети не гарантирует, что связь не оборвётся позже. Ошибка пакетов приводит к ненулевому результату шага и состоянию `failed`, не `complete`. Система может остаться частично установленной. **Отдельного безопасного восстановления/кнопки повтора после такой ошибки пока нет**; автоматические повторы касаются сетевых запросов APT, не произвольной перезаписи диска.
- Состояние редакции: `/var/lib/erodist/installation.json`. Лог пакетов на целевом диске: `/var/log/installer/erodist-edition.log` (root).
- Штатное приветствие Mint также может появиться. Подразделы центра настроек открывают штатные модули Mint/Cinnamon; это не их полная замена.
- Детекция VMBus помогает диагностике Hyper-V, но не исправляет производительность сама по себе. Причина ранее замеченных тормозов ещё не установлена.
- Старые приложения EroDist, телефонная интеграция и отдельный поиск не возвращены.

## Проверки и сборка

Автоматизация проверяет GPG/SHA256 исходного Mint, unit-тесты, сборку зарегистрированных `.deb`, симуляцию зависимостей трёх редакций в Mint rootfs, порядок плагинов Ubiquity, GTK-интерфейсы под Xvfb и состояния асинхронной проверки сети, manifests, BIOS/UEFI-записи и SHA256 результата. Это **не** полноценная установка/загрузка ОС и **не** измерение скорости Hyper-V.

[План ручной проверки перед стабильной 1.0.0](docs/1.0-release-checklist.md).

```sh
python3 -m unittest discover -s tests -v
bash scripts/build-packages.sh
```

Полный remaster: Linux/root, сеть к Mint/Ubuntu, свободный диск, xorriso, squashfs-tools, dconf-cli, gnupg, curl, xvfb и xauth:
```sh
sudo bash scripts/build.sh
```

Два пакета: `erodist-system` остаётся в установленной ОС, `erodist-installer` удаляется из неё как live-only. Пакетная база, OS identity, пользователи, обновления и storage backend Mint сохраняются. Подпись Mint удостоверяет только исходник, не изменённый EroDist ISO. ZIP Actions временный, собственный публичный ISO-хостинг не заявляется: предыдущая попытка переноса в preview была заблокирована средой.

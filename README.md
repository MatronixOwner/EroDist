# Обычный Linux Mint Cinnamon

Все собственные компоненты EroDist удалены из текущей версии репозитория:
оформление, обои, приложения, установщики, ремастеринг и GitHub Actions.
Здесь больше нет собственного дистрибутива или сборщика ISO.

Используется **оригинальный Linux Mint Cinnamon без изменений**.

## Скачать

- [Официальный сайт Linux Mint](https://linuxmint.com/download.php)
- [Оригинальный ISO Linux Mint 22.3 Cinnamon, 64-bit — одним файлом](https://mirrors.edge.kernel.org/linuxmint/stable/22.3/linuxmint-22.3-cinnamon-64bit.iso)
- [SHA256 исходного ISO](https://mirrors.edge.kernel.org/linuxmint/stable/22.3/sha256sum.txt)
- [Подпись списка контрольных сумм](https://mirrors.edge.kernel.org/linuxmint/stable/22.3/sha256sum.txt.gpg)

Это официальный исходный образ Mint, а не прежний ремастер EroDist.
Пересобирать ISO, скачивать части и запускать наши скрипты не нужно.
Установщик, программы и оформление — штатные Linux Mint.

Для Hyper-V создайте отдельную VM и сначала используйте пустой виртуальный диск.
Установка может удалить данные: сохраните резервные копии.

История Git и ранее опубликованные GitHub Releases не удалены.
Старые образы EroDist не являются обычным Linux Mint; для чистой установки
используйте только официальный ISO по ссылке выше.

# Переход EroDist на KDE neon

Выбрана пользователем KDE neon User Edition / Plasma. Mint-сборка сохранена как предыдущая, её автоматическая сборка при push отключена. Новый образ не считается готовым, пока не зафиксирован и проверен оригинал neon и не адаптирован его фактический установщик.

Этап 1: аудит официального образа. Этап 2: отдельные пакеты Qt/Plasma и перенос редакций без зависимостей от Mint/Ubiquity. Этап 3: сборка ISO и одного ZIP; проверка интерфейса и установки на новой основе отдельно от Mint.

# EroDist с нуля на KDE neon

## Текущее решение пользователя

«Переносить не будем, начинаем с нуля». Предыдущий план миграции функций отменён. KDE neon Desktop User Edition остаётся выбранной основой; новый проект начинается с чистой системы и штатного установщика.

- Home / Pro / Program и прежние приложения/мастера не переносятся автоматически.
- Существующий `packages/neon-system` — прежний экспериментальный прототип, не обязательный компонент нового образа.
- Новый состав, интерфейс и этапы разработки определяются заново. Собственная тема или приложение не считаются согласованными только потому, что они были в предыдущем плане.
- Старые исходники не удаляются. Подготовка чистого исходного ISO выполняется `scripts/neon-clean-iso.sh` через `.github/workflows/neon.yml`; старый Qt-аудит при push больше не запускается.

## История отменённого плана переноса

Пользователь выбрал **KDE neon Desktop User Edition / Plasma**. Это смена основы, не переименование Mint. Старые Mint-пакеты, скрипты и выпуски сохранены как резерв; автоматическая Mint-сборка при push отключена.

## Проверено на исходном ISO

Официальная страница neon на момент аудита указывала на `desk/user/20261025-1825`, а не старый несуществующий `user/current`. Точная ссылка, SHA256 и полный fingerprint ключа закреплены в `source.json`. Подпись ISO проверена GPG; повторная проверка сверяет также закреплённые fingerprint и SHA256.

- Ubuntu 24.04 noble, Plasma 6.8.1, Calamares 3.4.2.
- Фактическая конфигурация установщика: **`/calamares/desktop/`**. Нельзя переносить Mint/Ubiquity-плагин или подменять предполагаемый `/etc/calamares` без проверки.
- Firefox уже есть в исходной системе. Отдельного подтверждения требуют офисный набор Home, пакетные планы Pro/Program и доступность i386.
- Пакет `erodist-neon-system` установлен через APT в извлечённый настоящий rootfs neon. Добавлены только QtGui/QtWidgets PySide6 того же выпуска 6.11.1, без обновления системных пакетов.
- Нативное окно Qt прошло smoke, переключение всех разделов, проверку границ содержимого прокрутки в 800×600 / 1024×768 и 800×600 со шрифтом 13. Проверено завершение фонового чтения сведений. Снимки — реальные окна в **offscreen Qt**, не рабочий стол Plasma и не мастер установки.
- [Успешная проверка исходника bbd9d36](https://github.com/d50130483-ship-it/EroDist/actions/runs/40741383861). Ранний smoke обнаружил падение при передаче результата из worker в GUI; заменено явным queued Qt-slot, повторный запуск прошёл.

## Реализовано в отдельном пакете

`packages/neon-system/`: нативный центр управления на Qt 6/PySide6, запуск штатных модулей KDE, сведения о системе и сохранение только показанного локального отчёта по явному нажатию. Нет GTK/Cinnamon/Ubiquity-зависимостей и фоновой службы.

Пакет также содержит графитовую цветовую схему, существующий выбранный чёрный градиент, значок EroDist, Plasma global theme и сценарий нижней панели. Настройки применяются к шаблону **новых пользователей**, не переписывая существующие личные раскладки. Нет собственного телефонного сервиса или отдельного поискового виджета. Фактический вид Plasma, первый вход и корректность сценария панели ещё требуют проверки в загруженной новой системе; offscreen-тест Qt это не подтверждает.

Локальная упаковка: `bash scripts/neon-package.sh`. Результат в игнорируемой `artifacts/`; сборка не включает `__pycache__` и `.pyc`. В CI публикуется пакет и снимки инспекции, **это не ISO и не дистрибутив для установки**.

## Оставшиеся задачи прежнего плана (отменены)

- Перенос выбора Home / Pro / Program в процесс Calamares, явного согласия Steam, сетевых/дисковых проверок, прогресса и записи результата установки. Каталог перенесён как заготовка; он пока не устанавливает программы. Пакетные имена требуют проверки на neon, включая Godot.
- Qt-первый запуск, адаптация загрузочного экрана/входа и брендинга установщика.
- Отдельный remaster-пайплайн neon, готовый ISO и один ZIP с полным ISO.
- Полная загрузка Plasma, установка в VM и отдельное тестирование Hyper-V. Результаты Mint к neon не относятся.

**Нового EroDist neon ISO пока нет.** Workflow сейчас выполняет аудит и проверку Qt, а не сборку дистрибутива. Метаданные alpha в пакете — версия разрабатываемого пакета, не объявление готового выпуска ОС.
